# Minecraft Skin Generator

Benvenuto nel generatore procedurale di skin per Minecraft più  della rete! Questo strumento permette di creare skin complete (64x64) utilizzando algoritmi di rumore procedurale per texture uniche e professionali.

## 🚀 Caratteristiche
- **Texture Procedurale:** Dimentica i colori piatti. Grazie al rumore di Perlin, ogni skin ha sfumature naturali e dettagliate.
- **Layout 3D Completo:** Mappatura ufficiale di tutti i lati dei cubi (Testa, Corpo, Braccia, Gambe). Niente più buchi bianchi nell'editor!
- **Personalizzazione Totale:** Scegli il colore della pelle, degli occhi e decidi se aggiungere una bocca demoniaca.
- **Zero Dipendenze Pesanti:** Utilizza librerie "pure Python", evitando i fastidiosi errori dei compilatori C++ su Windows.

## 🛠️ Requisiti
Per far girare il generatore, hai solo bisogno di Python e di un paio di librerie:

```bash
pip install Pillow perlin-noise

```Bash
python skin_gen.py
